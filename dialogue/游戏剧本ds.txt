## 一、世界观总纲

### 核心设定

| 项目 | 内容 |
|------|------|
| **故事起因** | 冈崎梦美攻破博丽大结界，幻想乡面临暴露危机 |
| **紫的应对** | 将所有人的“魂”转移到梦境世界，创造30年循环的试炼场 |
| **梦境世界的性质** | 紫拥有管理员权限（哆来咪授予），可设定规则但不可直接改写记忆 |
| **梦境世界的时间** | 内部30年 ≈ 现实世界约1周 |
| **循环机制** | 紫在每次循环结束后判断“是否团结”，否则重置 |
| **本次循环的特殊性** | 紫察觉到“一丝微弱的变化”，这是唯一一次可能成功的机会 |
| **六大天仪** | 梦境世界与现实世界通道的“楔”，集齐后可打开/关闭通道 |
| **梦境终结的条件** | 紫判断“团结已达成”，通道打开，所有人回归现实 |

### 现实世界

| 项目 | 内容 |
|------|------|
| **梦美本体** | 已变成超级计算机，复制机投放梦境世界 |
| **新作角色** | 魔理沙、爱丽丝、灵梦、幽香（新作版本）在真实世界抵抗梦美 |
| **秘封组** | 莲子（梦美学生）、梅莉（拥有境界之力，未来紫）、堇子（梦美学生，梦境中与复制机搭档） |
| **神奈子与梦美的约定** | 真实世界达成，神奈子脑中埋有芯片 |

### 月都

| 项目 | 内容 |
|------|------|
| **月都的性质** | 真实世界的势力，被梦境世界一同卷入 |
| **月都在梦境中的状态** | 被修正了记忆，认为自己一直在梦境中追捕辉夜 |
| **绵月姐妹** | 保留记忆，暗中协助紫，在关键节点救场（“机械降神”式） |
| **稀神探女** | 被卷入，不知道这里是梦，率军进攻永远亭 |


## 二、梦境世界·重要角色定位

### 知道真相的人

| 角色 | 知道什么 | 动机 |
|------|----------|------|
| **八云紫** | 全部 | 终结梦境，所有人回到真实世界 |
| **八云蓝** | 失忆（对紫的气息有感应） | 被本能驱动，在冥界与妖梦对峙，看到折扇后逃跑 |
| **茨木华扇** | 不知道全部，但观察敏锐 | 作为神奈子的“顾问”，暗中观察局势 |
| **冴月麟** | 知道自己是梦境底层逻辑 | 保护梦境世界——那是她唯一能“活着”的地方 |
| **神奈子** | 通过梦美复制机确认世界是假的 | 取代紫，掌控梦境世界 |
| **神绮** | 知道自己是旧作碎片 | 在梦境终结前带魔界居民搬到幻想乡 |
| **绵月姐妹** | 保留完整记忆 | 协助紫，确保梦境终结后所有人安全返回 |
| **冈崎梦美（复制机）** | 知道自己是复制机 | 连通两个世界 |
| **旧作魔理沙/爱丽丝** | 不知道自己是旧作版 | 玩家全程看到的“主角” |

### 旧作角色·类别

| 类别 | 角色 | 说明 |
|------|------|------|
| **完全觉醒** | 冴月麟 | 梦境底层逻辑具现化 |
